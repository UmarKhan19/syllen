# Code of conduct

## Expected

Argue about the work, not the person. Assume the other person is trying to help. Say when you are unsure. A blunt "this breaks on Windows" is fine; contempt is not.

Not allowed:

- Harassment, insults, threats, or following someone across threads.
- Sexual attention or comments.
- Slurs, discriminatory jokes, or comments about someone's identity.
- Publishing someone's private information, including their real name, address, employer, or private messages.
- Spam, repeated off-topic comments, and reopening a closed decision to relitigate it.

## Where it applies

Issues, pull requests, discussions, commit messages, and any other project space. It also applies when you represent the project elsewhere.

## Reporting

Sensitive reports go to GitHub, not to a public issue or a maintainer email. There is no project email address or chat server, and I will not publish a personal address here.

Use GitHub's private abuse form at https://github.com/contact/report-abuse, or the **Report content** menu on the comment, issue, or profile. Include the repository `UmarKhan19/syllen`, the username, and links or screenshots. GitHub reviews that report itself; I only see it if GitHub contacts me about this repository.

For something that does not need privacy, open an issue in this repository and describe what happened. Leave out personal details about anyone involved.

Do not use the security advisory form for conduct reports. It is for vulnerabilities only.

## Enforcement

As the repository owner I can edit an issue or pull request, delete a comment, close or lock a thread, and block accounts from this repository. A first minor problem usually gets a warning and a request to stop. Threats, doxxing, and repeated behaviour after a warning get a block. GitHub can also act on accounts under its own terms.

I read reports when I have time and cannot promise a response time. Reports about an immediate safety risk should go to GitHub first.
